# ADR-0014: V2 采用数据优先的机构化市场研究与量化工作流

- 状态：Accepted
- 日期：2026-08-15
- 决策者：项目维护者；产品、交易、理财、量化、数据、架构和前端视角联合复审

## 背景

现有系统已经具备行情采集、板块排行、相对强弱、交易计划、交易流水、持仓和复盘等能力，
但产品入口仍偏向采集配置、薄排行和单证券图表。它可以查看已经知道的标的，却不足以回答
市场状态、交易活动向哪里集中、板块如何轮动、哪些股票值得进入候选，以及规则是否经得住
历史验证。

继续增加指标卡、榜单或单股技术图会扩大页面数量，却不能补齐全市场历史数据、时点行业成分、
资金事实、质量门禁和可重现实验这些基础能力。若没有这些数据，页面上的“资金流”“轮动”或
“全市场”结论也无法被审计。

## 决策

1. QTA V2 的一级产品空间固定为：市场研究、策略实验室、交易与复盘、数据中心和系统设置。
2. 市场研究采用自上而下证据链：市场趋势与风险状态、广度、流动性与交易活跃度、行业成交
   占比迁移、Provider 资金事实、相对强弱与动量、板块下钻、候选股票。
3. 市场研究首页不得退化为排行榜、自选股集合或单证券 K 线查看器；行情资产页继续承担数据
   检查和追溯职责。
4. 资金金额、资金强度、成交活跃度、价格表现、市场广度和流动性是不同概念，必须分别命名、
   展示单位、时间窗口、数据范围、Provider 和质量状态；不得以无解释总分替代证据。
5. V2 首期采用 A 股盘后日频。只有全市场证券池、日频历史、point-in-time 行业成分、资金事实
   和发布质量门禁通过后，才能使用“全市场资金流”或开展可重现量化研究。
6. 数据中心拥有采集、回补、标准化、质量、版本和发布；市场研究和策略实验室只读取已经发布
   的合格批次，不在页面查询过程中临时外联 Provider 或写回原始事实。
7. 复用 P1.0/P1.2/P1.5/P1.6/P1.7/P1.9/P1.10-A 与现有交易闭环，不重建第二套行情、板块或
   交易数据。旧 P1.10 的已实现能力作为兼容和引擎基线保留，其产品导航、页面编排和后续建设
   顺序由 V2 PRD 与机构化市场研究台设计取代。
8. 实现必须从 MR-0 数据与语义 PoC 开始。Provider 选择、权限、字段映射和阈值经 PoC 后用
   ADR/任务契约冻结，实施者不得自行补全或伪造。

## 原因

- 机构化研究需要趋势、广度、流动性、资金、相对强弱和质量证据相互确认，单一榜单无法承担。
- 数据先行可以避免对不完整样本做漂亮但错误的可视化，也为后续因子、回测和实验复现提供基础。
- 明确数据所有权和发布边界，可以让采集、研究、策略和交易模块各司其职，并保留现有资产。
- A 股盘后日频能够以可控成本先证明方法；盘中全市场和跨市场比较需要单独的数据与日历设计。

## 影响

- 新功能的最高产品基线改为 V2 PRD 和机构化市场研究台设计；旧 P1.10 文档继续用于解释现有
  实现和底层衍生引擎，不再单独决定 V2 页面。
- 下一项实施任务是 MR-0，而不是直接开发完整页面：先证明数据覆盖、口径、重算和质量门禁。
- 建设看板只能把 V2-0 标为设计冻结；MR-0 及后续能力在独立验收前均不得标为已交付。
- 现有采集、行情资产、板块排行和交易闭环不删除，按 V2 信息架构重新归位并逐步复用。

## 替代方案

- 继续扩展现有市场雷达：拒绝。当前样本和指标不足以支撑全市场资金与轮动结论。
- 先做完整高保真页面再补数据：拒绝。会再次产生 mock 驱动和假完整状态。
- 完全推倒现有市场数据模块重写：拒绝。现有采集、存储、调度和衍生引擎具有可复用价值。
- 首期建设全市场盘中实时系统：拒绝。成本、权限、交易日历和数据质量风险超出当前阶段。
