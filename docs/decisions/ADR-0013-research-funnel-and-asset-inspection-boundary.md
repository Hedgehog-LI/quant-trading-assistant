# ADR-0013: 市场研究采用三级决策漏斗并与数据资产检查分离

- 状态：Accepted
- 日期：2026-08-12
- 决策者：项目维护者；产品、交易、理财、量化、数据、架构和前端视角联合复审

## 背景

系统已经具备证券行情、板块排行、关注板块快照、采集任务、交易计划、交易流水和持仓账本等数据，但用户界面仍以采集配置和单证券查询为中心。单证券行情资产查看器能够核对数据，却不能帮助用户从市场中发现板块、从板块中收敛候选股票，也没有把个人交易上下文放进个股研究流程。

继续在单股 K 线页堆叠指标会扩大页面复杂度，但仍无法解决“先看哪里、再看什么、为什么看”的问题。

## 决策

1. 产品研究主流程固定为三级漏斗：市场雷达、板块详情与候选扫描、个股决策台。
2. 市场雷达负责方向发现；板块详情负责持续性研判和候选收敛；个股决策台负责结合个人持仓、计划、交易和风险做人工决策。
3. `/market-assets` 只作为行情数据详情和质量追溯工具，不再承担研究首页或机会发现职责。
4. P1.7 是衍生研究引擎，P1.10 是面向用户的研究工作流；两者不能各自建设一套重复页面。
5. 热力图、轮动矩阵、排行榜、候选表和多图网格共享同一数据批次、scope 和质量语义。
6. 所有候选和提醒提供白盒原因；不使用无解释总分，不生成自动买卖动作。
7. 个股点位严格区分真实成交、人工计划和经回测验证的策略候选。

## 原因

- 市场研究天然是从大范围逐步收敛的漏斗，而不是从已知代码反向扩散。
- 数据检查、研究筛选和个人交易决策有不同用户任务，拆开后更容易保持信息密度和金融语义清晰。
- 复用现有原始事实、P1.7 衍生指标和个人交易模块，可避免创建第二套行情或交易数据。
- 明确 scope 和指标性质可以避免把排行样本、成交活跃度或关注板块净流入误称为全市场资金流。

## 影响

- 导航将新增“市场研究”分组，行情采集和行情数据详情归入数据管理。
- P1.7 原有前端规格并入 P1.10 市场雷达和板块详情，不再单独建设平行分析页面。
- P1.9-B/C 的板块历史和多资产对比能力分别并入板块详情和候选扫描。
- 后续需要有界只读研究 read model 组合原始事实、衍生结果和个人上下文，但不改变其数据所有权。
- mock 规范需要改为虚构证券身份和持续水印，不能使用真实证券名称承载合成行情。

## 替代方案

- 继续增强单股行情资产页：拒绝，无法解决市场发现和候选收敛。
- 在现有板块管理页堆叠所有分析：拒绝，配置任务和研究任务会互相干扰。
- 首期直接做黑盒综合评分或 AI 荐股：拒绝，数据样本、回测和可解释性尚不满足要求。
- 完全复制成熟看盘软件：拒绝，本项目的差异化是个人计划、交易、持仓和复盘闭环。
