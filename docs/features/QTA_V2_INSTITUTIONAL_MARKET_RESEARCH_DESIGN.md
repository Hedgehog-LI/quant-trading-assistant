# QTA V2 机构化市场研究台设计方案

> 状态：`DECISION / FROZEN FOR IMPLEMENTATION`
>
> 版本：v1.0  
> 冻结日期：2026-08-15  
> 上位产品：`QTA_V2_QUANT_RESEARCH_PLATFORM_PRD.md`  
> 设计范围：市场全景、流动性与交易活跃度、资金与行业轮动、板块下钻、候选连接  
> 首期市场：A 股盘后日频；盘中和港美股分别后置

> 冻结说明：本文冻结页面研究顺序、图形职责、指标语义、下钻关系、数据门禁和 MR-0 至 MR-4
> 的交付顺序。具体 Provider、字段映射和阈值必须先经 MR-0 PoC 和任务契约确认；本文不等同于实现完成。

## 1. 设计结论

此前两版低保真原型仍属于“指标卡片拼盘”，不能作为投资研究台。问题不是缺一张走势图，而是没有建立机构化的自上而下研究顺序。

QTA V2 市场研究台必须按以下顺序回答问题：

```text
市场趋势和风险状态
    → 市场广度和流动性
    → 交易活动向哪些行业集中
    → 主动资金方向是否确认
    → 行业相对强弱如何轮动
    → 板块内部哪些股票贡献和跟随
    → 哪些股票进入可验证候选池
```

`DECISION`：市场研究首页不是排行榜，不是自选股集合，也不是单证券 K 线查看器，而是一套“市场状态 → 资金配置 → 板块轮动 → 候选下钻”的证据链。

## 2. 行业标杆拆解

### 2.1 交易所层

交易所提供成交额、成交量、换手率、证券状态和指数等事实。以上交所为例，其每日股票情况明确给出成交统计和换手率口径。交易所不负责替投资者生成“应该关注哪个板块”的结论。

### 2.2 专业终端层

TradingView 等终端通过走势图、热力图、筛选器和下钻帮助用户观察市场。热力图中面积和颜色承担不同维度，不能混成一个含义。

Relative Rotation Graph 类工具使用“相对强弱 + 相对动量 + 历史尾迹”展示板块相对基准的迁移，四个象限分别对应领先、转弱、落后和改善。QTA 使用其公开分析思想，但页面命名为“相对强弱-动量四象限”，不复制商标、专有指标或视觉样式。

### 2.3 机构买方层

Bloomberg 对资产管理工作流的公开描述是研究、组合构建、风险、交易和绩效归因的连接；PORT 将持仓、风险、收益和归因放在同一工作流，并强调数据校验和可重复报告。

私募或量化团队不会只看“主力资金净流入”，通常同时观察：

- 基准和行业趋势。
- 市场广度与内部结构。
- 成交活跃度和流动性。
- 波动、回撤和拥挤。
- 行业和风格因子暴露。
- 候选规则的历史有效性。
- 组合风险和实际收益归因。

### 2.4 市场流动性研究

BIS 将流动性拆成紧度、深度和韧性：

- 紧度：买卖价差和交易成本。
- 深度：大额交易可被市场吸收的能力。
- 韧性：冲击后价格和订单簿恢复的速度。

`DECISION`：只有日线和成交额时，QTA 只能展示“交易活跃度”和“价格冲击代理”，不能声称已经完整测量订单簿流动性。真实买卖价差、盘口深度和韧性需要 L1/L2 或逐笔数据，进入后续阶段。

## 3. 产品结构

市场研究域拆成四个连续页面：

```text
市场全景        今天市场处于什么状态？
资金与轮动      交易活动和主动资金偏向哪里？
板块研究        这个板块是持续、脉冲、分化还是拥挤？
候选与个股研究  哪些股票值得进入策略验证或人工计划？
```

默认入口为“市场全景”。页面共享市场、基准、截至日期和研究窗口，用户下钻时保持上下文。

## 4. 页面一：市场全景

### 4.1 页面职责

用户打开页面后，应在一分钟内回答：

1. 大盘趋势向上、震荡还是向下？
2. 上涨是普遍还是只靠少数权重股？
3. 成交活跃还是流动性收缩？
4. 波动和回撤是否正在放大？
5. 当前适合广泛寻找机会，还是只关注局部方向？

### 4.2 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 市场/基准  截至时间  1M/3M/6M/1Y  数据覆盖率  发布版本       │
├─────────────────────────────────────┬────────────────────────┤
│ A. 基准走势与成交量                  │ B. 市场状态证据         │
│ 沪深300/中证1000/上证指数            │ 趋势/广度/活跃度/波动   │
│ 价格走势 + MA20/MA60 + 成交量        │ 每项给事实与解释         │
├─────────────────────────────────────┼────────────────────────┤
│ C. 流动性与交易活跃度趋势            │ D. 市场广度趋势           │
│ 成交额 + 20日基线 + 价格冲击代理     │ A/D线 + 上涨占比 + MA覆盖 │
├─────────────────────────────────────┴────────────────────────┤
│ E. 行业成交占比迁移：20日堆叠面积图                           │
└──────────────────────────────────────────────────────────────┘
```

### 4.3 A. 基准走势与成交量图

#### 图形

- 默认显示沪深 300 K 线或收盘线。
- 下方显示全市场成交额柱状图。
- 可叠加 MA20、MA60，不默认堆叠 MACD、RSI 等常见看盘指标。
- 可切换上证指数、沪深 300、中证 500、中证 1000、创业板指。
- 可切换为指数归一化对比，比较大盘、成长、小盘的阶段表现。

#### 回答问题

- 价格趋势是否成立。
- 当前成交是否确认价格变化。
- 大盘股与小盘股风格是否分化。

#### 所需数据

- 指数日 K。
- 全市场日成交额。
- 交易日历。

### 4.4 B. 市场状态证据

不计算黑箱总分，只显示四类状态：

| 维度 | 示例结论 | 主要证据 |
|---|---|---|
| 趋势 | 中期向上，短期震荡 | 指数相对 MA20/MA60、均线斜率、阶段回撤 |
| 广度 | 偏弱，权重贡献较高 | 上涨家数、A/D 线、MA20/MA60 覆盖率 |
| 活跃度 | 活跃但集中 | 总成交额相对 20 日基线、前 5 行业成交占比 |
| 波动 | 正常偏高 | 20 日实现波动率、振幅、涨跌停数量 |

每项必须有“为什么”入口，展开后显示公式、时间窗口、原始值和数据来源。

### 4.5 C. 流动性与交易活跃度趋势图

本图至少分成三个同步子图，共享日期轴：

1. **全市场成交额**：每日成交额、20 日中位数、60 日中位数。
2. **成交扩散**：有多少股票成交额高于自身 20 日中位数。
3. **价格冲击代理**：全市场个股日频非流动性指标的中位数和高分位数。

高级数据具备后再增加：

- 买卖价差中位数。
- 盘口深度。
- 大额成交价格冲击。
- 冲击后的恢复速度。

`DECISION`：首期页面标题使用“流动性与交易活跃度”，并明确哪些属于真实微观结构指标、哪些只是日频代理。

### 4.6 D. 市场广度趋势图

共享时间轴展示：

- 每日上涨家数占比。
- 累计上涨-下跌线（A/D Line）。
- 高于 MA20 和 MA60 的股票比例。
- 20 日新高与新低家数。

用途是识别：

- 指数上涨但多数股票下跌的“窄幅上涨”。
- 指数横盘但内部股票逐步改善的“广度先行”。
- 指数新高但广度走弱的背离。

### 4.7 E. 行业成交占比迁移图

使用 20 或 60 个交易日堆叠面积图：

- 每一层代表一个申万一级行业。
- 层厚度代表该行业占全市场成交额的比例。
- 默认只强调前 8 行业，其余合并为“其他”。
- 悬停显示行业成交额、占比、较前一日和较 20 日均值变化。

该图回答“市场交易注意力正在往哪里移动”，比单日热力图更适合观察持续变化。

## 5. 页面二：资金与轮动

### 5.1 页面职责

区分并联合观察：

1. 成交活动向哪里集中。
2. 供应商口径主动资金偏向哪里。
3. 哪些行业相对基准正在改善或转弱。
4. 变化持续了多久，是否出现拥挤或背离。

### 5.2 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 1D/3D/5D/10D/20D  申万一级行业  资金Provider  数据质量       │
├───────────────────────────────────┬──────────────────────────┤
│ A. 行业资金与交易地图              │ B. 行业资金池明细表       │
│ 面积=成交占比，颜色=净流入强度     │ 金额/占比/强度/排名/连续性│
├───────────────────────────────────┼──────────────────────────┤
│ C. 行业资金累计走势图              │ D. 相对强弱-动量四象限    │
│ Top/Bottom行业累计净流入曲线       │ 带5/10日尾迹              │
├───────────────────────────────────┴──────────────────────────┤
│ E. 轮动带：每日资金、活跃度、相对收益和广度排名              │
└──────────────────────────────────────────────────────────────┘
```

### 5.3 A. 行业资金与交易地图

- 面积只代表成交额占比。
- 颜色可切换供应商净流入强度、相对收益或成交占比变化。
- 行业池使用互斥行业分类。
- 概念板块另开视图，不与行业汇总。

### 5.4 B. 行业资金池明细表

默认字段：

| 字段 | 含义 |
|---|---|
| 行业 | 申万一级行业名称 |
| 当日成交额 | 市场在该行业发生的交易金额 |
| 成交占比 | 行业成交额 / 全市场成交额 |
| 占比较 20 日变化 | 注意力是否持续迁入 |
| 窗口主动净流入 | 供应商定义的累计主动买卖净额 |
| 资金强度 | 净流入 / 成交额 |
| 行业排名 | 同一市场、同一口径的横向名次 |
| 连续性 | 连续流入/流出天数和排名变化 |
| 价格确认 | 相对基准收益是否同向 |
| 广度确认 | 板块内部上涨是否普遍 |

### 5.5 C. 行业资金累计走势图

- 默认选择净流入前 5 和净流出前 5 行业。
- Y 轴为窗口内累计供应商净流入金额。
- 可切换为资金强度，避免大行业天然金额较大。
- 每条线显示零轴、Provider、币种和口径。
- 不同 Provider 不画在同一条连续序列中。

该图解决“今天强”和“连续五天有资金进入”的差别。

### 5.6 D. 相对强弱-动量四象限

- X 轴：行业相对基准强弱。
- Y 轴：相对强弱的变化速度。
- 每个行业是一条带时间尾迹的路径。
- 四个象限：领先、转弱、落后、改善。
- 默认周频用于中期轮动，日频作为短期观察。

该图只描述相对价格轮动，不称为资金流向图。

### 5.7 E. 板块轮动带

单元格默认显示行业名次，例如 `3/31`；颜色表示方向和变化幅度。用户切换指标后，整张表只显示一个明确指标：

- 资金强度排名。
- 成交占比变化排名。
- 相对收益排名。
- 市场广度排名。

禁止默认展示混合总分。

## 6. 页面三：板块研究

### 6.1 页面职责

判断一个行业的强势是健康扩散、龙头独涨、短期脉冲还是过度拥挤。

### 6.2 核心图形

1. **板块指数与相对基准走势**：价格、相对收益、阶段回撤。
2. **资金与成交双轴趋势**：净流入柱 + 成交占比线。
3. **板块广度趋势**：上涨占比、MA20 覆盖率、新高/新低。
4. **成分股收益分布**：箱线图或直方图，避免只看龙头。
5. **龙头集中度趋势**：前 3/5 成分对成交额和收益的贡献。
6. **候选散点图**：X 为相对板块强弱，Y 为流动性，大小为成交额，颜色为风险状态。

### 6.3 板块阶段标签

标签必须由透明证据组合产生：

| 阶段 | 必要证据 |
|---|---|
| 改善 | 相对动量回升，广度改善，成交占比未显著下降 |
| 共振 | 资金、成交占比、相对收益和广度同时改善 |
| 分化 | 板块价格上涨，但广度走弱或收益集中在少数股票 |
| 拥挤 | 成交占比、换手和波动处于历史高位，资金边际放缓 |
| 转弱 | 相对收益、资金和广度同步下降 |

页面展开标签后必须显示命中的原始证据，不显示只有模型知道的分数。

## 7. 页面四：候选与个股研究

### 7.1 候选发现

候选池首先过滤不可交易和流动性不足证券，再按冻结研究模板排序。

默认视图不是逐只点开，而是同屏小多图：

- 每行 4 至 6 只候选。
- 每只显示 60 日价格走势、成交量、所属行业和入选证据。
- 支持按行业、策略来源、流动性和风险过滤。
- 点击后进入个股研究台。

### 7.2 个股研究走势图

主图必须包含：

- K 线和成交量。
- 真实成交买入/卖出标记。
- 人工计划条件和失效位。
- 策略历史候选点，使用不同形状，不能与真实成交混淆。
- 相对所属行业和相对基准收益副图。
- 个股流动性、资金和板块阶段证据。

## 8. 关键指标与计算口径

### 8.1 市场成交活跃度

```text
activityRatio(t) = marketTurnover(t) / median(marketTurnover[t-19:t])
```

默认显示原始成交额和相对基线，不把比值单独称为流动性。

### 8.2 行业成交额占比

```text
sectorTurnoverShare(s,t) = sectorTurnover(s,t) / marketTurnover(t)
```

### 8.3 市场广度

```text
advanceRatio(t) = advancingStocks(t) / validStocks(t)
aboveMa20Ratio(t) = stocksAboveMa20(t) / stocksWithEnoughHistory(t)
adLine(t) = adLine(t-1) + advancingStocks(t) - decliningStocks(t)
```

### 8.4 资金强度

```text
flowIntensity(s,w) = sum(providerNetFlow(s,w)) / sum(sectorTurnover(s,w))
```

供应商净流入是 Provider 事实，不由 QTA 从价格涨跌猜测。

### 8.5 日频价格冲击代理

```text
illiquidityProxy(i,t) = abs(return(i,t)) / turnoverAmount(i,t)
```

全市场图使用合格股票的中位数和高分位数。该值只作为日频价格冲击代理，不替代买卖价差和订单簿深度。

### 8.6 交易集中度

首屏使用简单可解释的 Top 3/Top 5 行业成交占比；高级视图可增加 HHI，但不得只展示 HHI 而不解释。

## 9. 数据需求

### 9.1 V2 市场研究最低数据集

| 数据集 | 用途 | 首期来源候选 |
|---|---|---|
| 证券主数据和交易状态 | 股票池、停复牌、上市退市 | 现有 + Tushare |
| 权威交易日历 | 日期对齐、缺口判断 | Tushare/交易所 |
| 全市场股票日 K | 趋势、广度、波动、候选 | Tushare |
| 日成交额和换手率 | 活跃度、流动性代理 | Tushare daily/basic |
| 主要指数日 K | 基准趋势和相对收益 | Tushare/现有 Provider |
| 申万行业体系 | 互斥行业池 | Tushare |
| Point-in-time 行业成分 | 历史聚合、避免未来函数 | Tushare index_member_all |
| 行业/概念资金流 | 供应商口径资金证据 | Tushare THS/DC，先做 PoC |
| 涨跌停和停牌数据 | 可交易性和风险状态 | Tushare/交易所 |
| ETF 日线和份额 | 配置资金证据 | Tushare，后续阶段 |

### 9.2 历史范围

- 第一批：2021-01-01 至今的 A 股日频数据。
- 质量通过后：扩展至 2016 年。
- 市场全景和板块轮动至少需要 120 个合格交易日才显示中期结论。
- 新上市股票按实际可用历史计算，不强行填充。

### 9.3 数据发布门禁

研究页面只读取同一发布批次的数据：

```text
股票日线 + 指数日线 + 行业成分 + 行业资金流 + 质量报告
```

全市场横截面覆盖不足、行业成分版本缺失或资金 Provider 无权限时，对应图形明确阻断，不使用上一个指标替代当前指标含义。

## 10. 现有能力复用与改造

### 10.1 直接复用

- `stock_basic` 和统一证券标识。
- `stock_daily_bar`、分钟 K、行情快照和数据水位。
- 现有采集计划、同步任务、调度器、DB claim、幂等和失败记录。
- Longbridge 实时和重点证券采集能力。
- 板块身份、关注、排行批次、板块快照和成员快照。
- P1.7 的原始事实、衍生指标、提醒事件三层边界。
- 当前相对强弱和轮动持续性最小实现。

### 10.2 保留代码但重新定位

- `/market-workspace`：迁入数据中心/自动采集。
- `/market-assets`：迁入数据中心/数据资产详情。
- `/market-segments`：迁入数据中心/行业目录与采集。
- 当前 `/market-research`：保留路由和可复用组件，重构为市场全景入口。

### 10.3 必须新增

- A 股全市场日频 Provider 和历史回补。
- Point-in-time 行业成分。

## 12. 验收标准

### 市场全景

- 首屏至少包含一张市场走势图、一张流动性/活跃度趋势图和一张市场广度趋势图。
- 用户能够区分指数上涨、普遍上涨和少数权重股上涨。
- 用户能够看出当前成交额相对历史基线是在扩张还是收缩。
- 所有状态均可追溯到原始值和时间窗口。

### 资金与轮动

- 用户能够看出行业成交占比在 20 日内如何迁移。
- 用户能够同时看到行业净流入金额、资金强度、排名和持续时间。
- 用户能够区分资金流、交易活跃度、相对价格和市场广度。
- 轮动带数字有明确单位或排名含义，不出现无标签百分数。

### 数据正确性

- 行业历史聚合使用当日有效成分，不使用当前成分回填过去。
- 概念板块不汇总成全市场 100%。
- Provider、币种、分类体系和时间窗口不静默混算。
- 数据不完整时阻断结论，而不是显示貌似完整的图。
